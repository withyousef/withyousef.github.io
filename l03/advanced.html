تمارين الورق — الشروط

التمارين دى تُحلّ بالقلم على الورق، من غير تابلت ومن غير تشغيل. الهدف إن الطالب يمشى مكان الكمبيوتر سطراً بسطر ويقول أنهى فرع هيشتغل قبل ما يقول الناتج. الحلول مخفية؛ افتحها بعد ما تجرّب.

إعداد: يوسف زكريا التهامى · تأسيس البرمجة — بكالوريا ٢٠٢٧

الاسمالتاريخ
ورقة الطلاب بتطلع بمساحة إجابة وبدون حلول.
المستوى المتقدم — للى خلّص بدرى
٠٥

تتبّع كامل بجدول قيم

٦ دقائق
let x = 4;
let y = 9;

x = x * 2;

if (x > y) {
  y = y + x;
} else {
  x = x + y;
}

if (y > 15) {
  console.log("big");
} else {
  console.log("small");
}

console.log(x);
console.log(y);

ارسم جدولاً بعمودين x وy، واكتب قيمة كل واحد بعد كل سطر. وبعدين اكتب اللى هيتطبع بالترتيب.

الحل
السطرxyاللى حصل
let x = 4;4—اتعمل درج فيه ٤
let y = 9;49اتعمل درج فيه ٩
x = x * 2;89٤ فى ٢ يبقى ٨
if (x > y)89٨ أكبر من ٩؟ غلط
x = x + y;179مشينا فى else
if (y > 15)179٩ أكبر من ١٥؟ غلط

الناتج: small ثم 17 ثم 9

الفخ هنا فى الشرط التانى: الطالب بيبص على x اللى بقت ١٧ وبيقول big. لكن الشرط بيسأل عن y، وy ما اتغيّرتش خالص لأننا مشينا فى فرع else. الجدول هو اللى بيمنع الغلطة دى، لأنه بيخلّى العمودان قدام عينك.

٠٦

فين الغلط؟ ثلاثة أغلاط، حدّدهم وصحّحهم

٦ دقائق
let mark = 95;

if (mark >= 50) {
  console.log("C");
} else if (mark >= 70) {
  console.log("B");
} else if (mark = 85) {
  console.log("A");

المطلوب إن الكود يطبع A للقيمة دى. غلطتان منهما ما بيطلعوش أى رسالة خطأ خالص.

الحل
  1. الترتيب مقلوب: الشرط الأوسع mark >= 50 فى الأول، فأى طالب ناجح هياخد C والسلسلة بتقفل. القاعدة: من الأضيق للأوسع. ده غلط صامت — الكود بيشتغل تمام وبيدّى نتيجة غلط.
  2. السطر ٧: علامة يساوى واحدة mark = 85 — دى إسناد مش مقارنة. الصح mark >= 85. وده غلط صامت تانى.
  3. السطر الأخير: ناقص قوس معقوف يقفل. ده الغلط الوحيد اللى المتصفح هيشتكى منه.

الكود بعد التصحيح:

let mark = 95;

if (mark >= 85) {
  console.log("A");
} else if (mark >= 70) {
  console.log("B");
} else if (mark >= 50) {
  console.log("C");
}

ولو الطالب زوّد else فى الآخر تطبع F، ده أحسن من المطلوب — امدحه، لأنه فكّر فى الحالة اللى مالهاش فرع.

٠٧

اكتب برنامجاً كاملاً

٧ دقائق

مدرسة بتحدّد نتيجة الطالب بشرطين: الدرجة والحضور. اكتب كوداً يحطّ الدرجة فى mark والحضور فى attend، ويطبع:

  • Pass لو الدرجة ٥٠ فأكتر والحضور ٧٥ فأكتر.
  • Attendance لو الدرجة ٥٠ فأكتر بس الحضور أقل من ٧٥.
  • Fail لو الدرجة أقل من ٥٠، مهما كان الحضور.

اكتبه بطريقتين: مرة بالتعشيش، ومرة بسلسلة else if بدون تعشيش. وقول أنهى واحدة أوضح فى رأيك وليه.

الحل

الطريقة الأولى — بالتعشيش:

let mark = 72;
let attend = 60;

if (mark >= 50) {
  if (attend >= 75) {
    console.log("Pass");
  } else {
    console.log("Attendance");
  }
} else {
  console.log("Fail");
}

الطريقة التانية — سلسلة بدون تعشيش:

let mark = 72;
let attend = 60;

if (mark < 50) {
  console.log("Fail");
} else if (attend >= 75) {
  console.log("Pass");
} else {
  console.log("Attendance");
}

الاتنين صح ويدّوا نفس النتيجة بالظبط. مفيش إجابة واحدة عن «أنهى أوضح» — المهم إن الطالب يبرّر. لكن لو حد قال إن التانية أوضح لأنها مستوى إزاحة واحد، ده رأى ناضج جداً لطالب فى السنة دى.

الغلط المتوقع: كتابة ثلاث if منفصلة بدل السلسلة. جرّب معاه قيمة mark = 30 وattend = 90 وشوف هيطبع كام سطر — الشروط المنفصلة بتشتغل كلها، والسلسلة بتشتغل مرة واحدة.

المستوى الأساسى — مطلوب من الكل

التمارين دى مكانها الطبيعى فى بلوك الشرح نفسه، بس محطوطة هنا علشان كل ورق المحاضرة يبقى فى صفحة واحدة.

٠١

إيه اللى هيتطبع؟

دقيقتان
let age = 15;

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}

console.log("End");

اكتب الناتج، وجنبه عدد السطور اللى هتتطبع.

الحل

Minor ثم End — سطران.

الشرط رجّع غلط فمشينا فى else. والسطر الأخير برّه الشرط خالص، فبيشتغل مهما كانت الإجابة. الغلط الشائع: كتابة ثلاثة سطور، وده معناه إن الطالب فاكر إن الفرعان بيشتغلوا مع بعض.

٠٢

سلسلة واحدة، ثلاث قيم

٤ دقائق
if (n >= 90) {
  console.log("A");
} else if (n >= 80) {
  console.log("B");
} else if (n >= 60) {
  console.log("C");
} else {
  console.log("F");
}

املأ الجدول: إيه اللى هيتطبع لكل قيمة من قيم n؟

قيمة nالمطبوعليه
95
85
45
الحل

95 بتطبع A — أول شرط اتحقق فوراً.

85 بتطبع B — الأول فشل، والتانى نجح. ولاحظ إن 85 >= 60 صحيحة كمان، ومع ذلك C ما اتطبعتش.

45 بتطبع F — كل الشروط فشلت، فوصلنا لـelse.

٠٣

املأ جدول الحقيقة

٣ دقائق

اكتب فى كل خانة true أو false. حاول من غير ما ترجع للجدول اللى فى الشرح.

التعبيرالناتج
10 > 5 && 2 > 1
10 > 5 && 2 > 8
10 < 5 || 2 > 1
!(10 > 5)
7 != 7
الحل

true · false · true · false · false

الصف التانى والتالت هما الفارق: نفس فكرة الشرطين، بس && عايزة الاتنين و|| بتكتفى بواحد. والصف الأخير هو أكتر واحد بيتغلط فيه — 7 != 7 بتسأل «مختلفين؟» والإجابة لأ.

٠٤

صحّح السطر

دقيقتان

الكود ده المفروض يطبع Fail لأن الدرجة ٣٠. بس هو بيطبع Pass. حدّد الغلط واكتب الصح.

let mark = 30;

if (mark = 50) {
  console.log("Pass");
} else {
  console.log("Fail");
}
الحل 
if (mark === 50) {

علامة يساوى واحدة معناها «حُطّ فى» زى ما اتعلّمنا فى المحاضرة الأولى. فالسطر ده بيحطّ ٥٠ فى mark بدل ما يسأل، والشرط بياخد الناتج ويعتبره صح.

وأخطر حاجة فيه: مفيش رسالة خطأ. البرنامج بيشتغل لآخره، والدرج mark بقى فيه ٥٠ من غير ما حد يطلب. اسأل نفسك قبل كل شرط: أنا بسأل ولا بحطّ؟
