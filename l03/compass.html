أسئلة البوصلة

ستة أسئلة عن الشرط والقرار، تُوزّع فى أول خمس دقايق. أول سؤال فيها هو نفسه السؤال اللى قفلنا بيه المحاضرة اللى فاتت، وآخر سؤال فيها هو نفسه أول تمرين فى الواجب — فالورقة بتقفل الحلقة من الطرفين.

تعليمات الطقس — إزاى تستخدم الورقة
٠١

وزّعها فى أول خمس دقايق

قبل أى شرح وقبل اختبار المحاضرة السابقة. الطالب يحطها قدامه على الترابيزة طول الحصة.

٠٢

اقراها بصوت عالٍ

مرة واحدة، من غير ما تجاوب على أى سؤال. لو طالب جاوب، قول له: «سيبها للآخر».

٠٣

يكتب بالرصاص أثناء الحصة

أول ما إجابة تتوضح، يسجّلها فى ساعتها. مش فى الآخر دفعة واحدة.

٠٤

حُلّوها سوا فى الآخر

بصوت الطلبة مش بصوتك. ده البلوك الوحيد اللى ما يتقطعش مهما ضاق الوقت.

الجملة اللى تتقال حرفياً

«الورقة دى مش امتحان ومش هتتصحح. دى بوصلة — لو فى آخر الحصة عرفت تجاوب على الستة، يبقى الحصة نجحت. والسؤال الأول فيها هو اللى سيبناه معلّقاً الأسبوع اللى فات».

الاسمالتاريخ

الورقة دى مش امتحان ومش هتتصحح. دى بوصلة. كل سؤال فيها إجابته هتتوضح فى لحظة معينة من الحصة — أول ما تعرف الإجابة، اكتبها بالرصاص. وفى آخر الحصة هنحلّهم سوا.

١) عرفنا إن المقارنة بترجّع true أو false. طيب إيه اللى يخلّى البرنامج يتصرّف على أساسها — ينفّذ سطراً لو الإجابة صح ويتخطّاه لو غلط؟

٢) الكود ده هيطبع إيه بالظبط؟ واكتب عدد السطور اللى هتتطبع.

let mark = 30;

if (mark >= 50) {
  console.log("Pass");
}

console.log("Done");

٣) فى if ومعاها else — كام فرع ممكن يشتغل من الاتنين؟ ولا واحد، ولا واحد بالظبط، ولا الاتنين؟

٤) فى سلسلة else if فيها شرطان الاتنين صح — مين اللى بيشتغل فيهما؟ وليه؟

٥) العلامة != معناها إيه؟ و!true بترجّع إيه؟

٦) اعمل جدولاً بعمودين a وb، واكتب قيمة كل واحد بعد كل سطر، وفى الآخر اكتب اللى هيتطبع.

let a = 10;
let b = 4;

if (a > b) {
  a = a - b;
} else {
  b = b - a;
}

console.log(a);
console.log(b);

توقيت وضوح الإجابات: السؤالان ١ و٢ بعد قسم أول if، و٣ فى بلوك else، و٤ فى بلوك else if وهو أهمهم، و٥ فى بلوك != والنفى، و٦ فى بلوك التتبّع اليدوى قبل الواجب مباشرةً.
