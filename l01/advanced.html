تمارين الورق

التمارين دى تُحلّ بالقلم على الورق، من غير تابلت ومن غير تشغيل. الهدف بناء مهارة التتبع — اللى الطالب ما اتدربش عليها ولا مرة السنة اللى فاتت. الحلول مخفية؛ افتحها بعد ما تجرّب.

إعداد: يوسف زكريا التهامى · تأسيس البرمجة — بكالوريا ٢٠٢٧

الاسمالتاريخ
ورقة الطلاب بتطلع بمساحة إجابة وبدون حلول.
المستوى المتقدم — للى خلّص بدرى
٠٥

تتبع بمتغيرين

٤ دقائق
let a = 5;
let b = 2;
a = a + b;
b = a + b;
console.log(a);
console.log(b);

اكتب قيمة a وقيمة b بعد كل سطر، وبعدين الناتج المطبوع.

الحل

a = 5 + 2 = 7، وبعدين b = 7 + 2 = 9 — لاحظ إن a بقى ٧ خلاص.

الناتج: 7 ثم 9

الفخ هنا: الطالب بيستخدم قيمة a القديمة (٥) فى السطر الرابع. ده أشيع خطأ فى التتبع.

٠٦

فين الغلط؟ ثلاثة أغلاط، حدّدهم وصحّحهم

٥ دقائق
let 2price = 30;
let my price = 10;
total = price + 5
الحل
  1. let 2price = 30; — الاسم ما يبدأش برقم. الصح: let price2 = 30;
  2. let my price = 10; — فيه مسافة جوه الاسم. الصح: let myPrice = 10; أو my_price.
  3. total = price + 5 — غلطتان: المتغير total ما اتصرّحش بـlet، وناقص فاصلة منقوطة. الصح: let total = price2 + 5;
٠٧

اكتب برنامجاً كاملاً

٦ دقائق

طالب جاب ثلاث درجات: ٢٠ و١٨ و٢٥. اكتب كوداً يحطّ كل درجة فى متغير، ويحسب المجموع فى متغير رابع، ويطبع جملة على شكل Total = 63.

الحل 
let mark1 = 20;
let mark2 = 18;
let mark3 = 25;
let total = mark1 + mark2 + mark3;
console.log("Total = " + total);

حل تانٍ مقبول: التراكم — let total = 0; ثم total = total + mark1; وهكذا. لو طالب عملها كده، امدحه صراحةً: دى الفكرة اللى هتفتح الحلقات فى المحاضرة ٤.

المستوى الأساسى — مطلوب من الكل

التمارين دى مكانها الطبيعى فى بلوك الشرح نفسه، بس محطوطة هنا علشان كل ورق المحاضرة يبقى فى صفحة واحدة.

٠١

تتبع: إيه اللى هيتطبع؟

دقيقتان
let x = 2;
x = x + 5;
console.log(x);
الحل

7 — اليمين الأول: x + 5 والـx فيه ٢، يبقى ٢ + ٥ = ٧، والسبعة بتتحط فى x.

٠٢

املأ جدول قيمة n بعد كل سطر

٣ دقائق
let n = 10;      // (1)
n = n - 4;       // (2)
n = n * 3;       // (3)
console.log(n);  // (4)
بعد السطر(1)(2)(3)
قيمة n
الحل

(1) = 10 · (2) = 6 · (3) = 18 · والمطبوع = 18.

٠٣

اكتب سطراً واحداً

دقيقة

اكتب السطر اللى بيعمل متغيراً اسمه age وبيحط فيه القيمة ١٦.

الحل 
let age = 16;

مقبول كمان لو كتبها فى سطرين: let age; ثم age = 16;

٠٤

اكتب ثلاثة أسطر

٣ دقائق

اعمل متغيراً اسمه pens قيمته ٤، بعدين زوّده ٣، بعدين اطبعه.

الحل 
let pens = 4;
pens = pens + 3;
console.log(pens);   // 7

الخطأ المتوقع: كتابة let تانى فى السطر التانى. صحّحه فوراً وبهدوء: «الدرج اتعمل مرة واحدة بس».
