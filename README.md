# تأسيس البرمجة — بكالوريا ٢٠٢٧

محاضرات وأوراق تمارين تفاعلية لمادة **البرمجة** — الصف الثانى الثانوى، البكالوريا المصرية.

**الرابط:** https://withyousef.github.io/

## إيه اللى فى كل محاضرة

- **الشرح** كامل بأقسامه، ومعاه الواجب فى آخره.
- **تدريب التابلت** — تمارين متدرّجة بخانات إجابة بتتحفظ على الجهاز.
- **ورقة التمارين** — بالإجابة والشرح خطوة بخطوة ومعاه رسم توضيحى لكل خطوة، وفى آخرها محرّر كود شغّال جوه الصفحة.
- **تمارين المستوى المتقدم** للى خلّصوا بدرى، وأوراق التسخين والاختبار بتصحيحها.

## بتشتغل أوفلاين

الصفحات **مكتفية بذاتها** — الرسوم والشعار والمحرّر جواها. يعنى الطالب يقدر:

- يفتحها بالرابط على طول، **أو**
- يحفظها من المتصفح (`Ctrl+S`) ويشتغل عليها من غير إنترنت خالص.

المحرّر بيشتغل جوه `Web Worker` معزول، فالحلقة اللانهائية بتتقطع بمهلة والصفحة ما بتعلّقش.

## الملفات

```
index.html    صفحة الكورس
assets/       التنسيق المشترك والشعار
l01/          المحاضرة الأولى — البداية وأول كود حقيقى
l02/          المحاضرة التانية — الأنواع والتحويل
l03/          المحاضرة التالتة — الشروط
```

كل محاضرة بتتنشر **بعد حصتها**، فاللى مش موجود هنا لسه ما اتشرحش.

الصفحات دى **مولّدة** من مستودع خاص فيه المصدر والبيانات وأدوات الفحص. التعديل هنا بيضيع مع أول نشر.
